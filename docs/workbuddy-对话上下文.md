已在本机建好两个每日定时任务，**都处于 ACTIVE，开机就会自动跑**。

## 定时任务 1 · 每天 09:00「排名简报 + 今日行动包」

它会自动做这些，然后把结果推到你面前：

1. 拉官方 `RANKING.md`，定位你的名次和 Star 数
2. 读参赛 Issue 有没有官方新回复
3. **按星期决定今天该发哪个平台**，从文案库里取出那条**成品文案原样给你**（不用你自己找）
4. 生成 `今日行动包.md` 并弹给你，里面是可以直接复制粘贴的文字
5. 更新进度台账

平台轮转：周一 V2EX / 周二 即刻微博 / 周三 小红书 / 周四 朋友圈微信群 / 周五 掘金知乎 / 周六 官方 MCP 仓库展示 / 周日 复盘。

## 定时任务 2 · 每天 20:00「收尾检查 + 明日预告」

1. 再查一次 Star，算出**当天新增几个**
2. 检查 Issue 和评论有没有要回复的 —— **只起草好回复让你复制，不会替你发**（那需要你的登录态）
3. 核对今天三项动作有没有漏，漏了给补救建议
4. 预告明天的平台和文案

## 配套的两个文件

- **`冲榜进度.md`**（工作区）— 台账，定时任务自动维护，记着当前 Star、距上榜还差多少、每天做了什么。**放在仓库外，不会传到 GitHub**
- **`docs/冲榜宣传包.md`**（已上传仓库）— 文案库，定时任务每天从这儿取稿

## 顺手做的一件事

README 首屏加了一行 Star 引导：

> **如果这个「往回看」的方向你觉得有意思，右上角点个 ⭐ 就是对我最大的支持。**
> 本项目参加麦当劳开发者创新赛，官方排行榜按 Star 数排名。

来访者看完首屏就知道该怎么支持你，这比在文末藏一句转化率高不少。已重传生效。
