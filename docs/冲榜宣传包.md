## 零、先认清一件事：34 个 Star 是什么量级

不是"火"的量级，是**"让 34 个真人愿意点一下"**的量级。

换算一下：

| 渠道 | 保守估计 | 需要触达人数 |
|---|---:|---:|
| 微信私域（同事/同学/技术群） | 转化率 ~30% | 40 人 |
| 垂直社区帖子（V2EX / 即刻） | 转化率 ~2% | 800 阅读 |
| 技术长文（掘金 / 知乎） | 转化率 ~0.5% | 3000 阅读 |
| 小红书 / 朋友圈 | 转化率 ~1% | 1500 阅读 |

**结论：私域是主力，公域是补充。** 别把希望全压在"写一篇爆款"上——34 个 star 里，至少 20 个应该来自你认识的人。

## 一、一句话钩子库（10 条，挑一条当主钩子）

发任何平台前，先选一条。钩子的作用是让人**停下来读完第一句**，不是介绍项目。

1. 你今年在麦当劳吃了多少卡路里？我写了个工具，把它做成了一份年报。
2. 所有人都想教你"下一顿怎么点更省钱"，没人想过"这一年你到底吃了什么"。
3. 接了麦当劳官方 MCP，把我一年的点单史编译成了九屏年度报告。
4. 162 单、10 万卡路里、50 个深夜——这是 AI 给我写的年度总结。
5. 你的麦当劳会员数据里，藏着一份比支付宝年账单更有烟火气的年终总结。
6. 用 Python 标准库手搓了个 MCP 客户端，就为了看看我一年吃了多少顿麦当劳。
7. 不做推荐、不做比价、不做决策——只做一份能晒的年度档案。
8. 数据全程在你自己电脑上跑，不上传、不过第三方服务器。
9. 最晚一单在凌晨 3:59，最多的一个月点了 23 单——报告替你记住了。
10. 别人做"下一单怎么省"，我做"这一年怎么过的"。

> **使用建议**：技术社区用 3 / 6 / 8；泛社区用 1 / 4 / 9；朋友圈用 2 / 7 / 10。

## 二、分平台文案（可直接复制，已填真实地址）

### 1. V2EX（技术社区 · 短帖，转化率最高）

**标题**：接了麦当劳官方 MCP，把一年的点单史做成了一份年度报告

**正文**：

```
最近麦当劳开放了个人数据的 MCP Server，我接进去做了个小东西：
把一年的点单记录聚合成一份九屏的个人年度报告——最爱单品 Top5、
逐月进食曲线、累计热量趣味换算、深夜点餐画像、积分过期体检。

技术上没什么炫技的，就是一次标准的 MCP Streamable HTTP 接入
（Python 标准库手搓的客户端，没用任何第三方包）+ 本地纯函数聚合
+ 单文件 HTML 输出。真正有意思的是三个数据坑：

1. 订单数和件数不是一回事，混着算会把"点了 3 份薯条"算成 3 单；
2. 算"平均深夜下单时刻"不能跨零点直接平均，22:47 和 00:58 平均是 12:32，
   得平移时间轴再折回来；
3. 餐品名和官方营养表对不上，做了三级匹配才把命中率拉起来。

数据全程在本地处理，不上传任何服务器，Token 只走环境变量。
仓库里有可直接复制的 JSON-RPC 调用示例，也写了工具选型的取舍。

https://github.com/vvvvv20252025/mcd-annual-report

投了麦当劳的开发者赛，按 Star 排名。如果这个"往回看"的方向你觉得有意思，
帮忙点个 Star 就很感谢。有问题欢迎直接开 Issue 聊。
```

## 三、每日 15 分钟运营 SOP

| 时间 | 动作 | 耗时 |
|---|---|---|
| 早上 | 看一眼自动化给的排名简报，记录当天 star 数 | 1 分钟 |
| 上午 | 发 1 条公域（V2EX / 即刻 / 小红书 轮换，别一天全发） | 5 分钟 |
| 中午 | 私聊 5 个人（带名字、带相关的话） | 5 分钟 |
| 晚上 | 回 1 条评论 / Issue，或者改一点 README | 4 分钟 |

**节奏原则**：
- 一周内把 5 个平台各发一遍，不要一天内全平台轰炸（会被判定为 spam）
- 私域每天 5 个人，一周 35 人，按 30% 转化就是 ~10 star
- 公域帖子**不重复发**，一个平台一个坑位，发完就换下一个

## 四、能提高转化的两个仓库侧改动

发出去之前，先确保来访者**点进来就想按 star**：

1. **README 首屏 3 秒内说清是什么** —— 现在是 GIF 打头，很好。但要保证 GIF 第一帧就是报告成品，不是代码。
2. **加一行"如何给我一个 Star"** —— 在 README 顶部加一句带链接的引导，转化率能提升一截：

```markdown
如果这个方向你觉得有意思，右上角点个 ⭐ 就是对我最大的支持。
```

## 五、绝对不能做的事
